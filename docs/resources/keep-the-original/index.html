Product thinking / editorial draft

Keep the original. Rethink the interpretation.

What preserved source responses change about refining business data.

On this pageA clean table is an interpretationSeparate receiving from understandingChange a rule without losing the recordAsk a better operational question

A clean table is an interpretation

Every transformation makes choices: which field is a price, which unit applies, what a missing value means. Those choices can change as a business or source system changes.

Separate receiving from understanding

Ground’s current development documentation describes an original-response layer, followed by refinement into source entities and cross-source mastering. Receiving data and interpreting it are distinct stages, with different responsibilities.

Change a rule without losing the record

When a refinement rule changes, the preserved response gives the pipeline a durable place to start again. The original is the evidence; the refined representation is something that can be rebuilt.

Ask a better operational question

Alongside “did the collection finish?”, ask “which interpretation produced this object?” Collection status, transformation status and the canonical record answer different questions. Good operations make those questions visible.
