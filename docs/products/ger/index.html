Ger

Keep your operating environment running.

Installation is the start. Keep configuration, software changes, diagnosis and recovery connected to the environment they affect.

Installation is a beginning.

Software still needs updates, monitoring, diagnosis and recovery after it arrives. Ger makes that ongoing operating responsibility part of the system.

A change needs
a return path.

Version management, staged delivery, applicable checks and rollback connect a proposed release to the environment it affects. A switch is not the same as a verified recovery.
