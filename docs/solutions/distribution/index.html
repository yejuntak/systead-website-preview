Orders, inventory and dispatch

Review an order against its dispatch records, retain the explanation and identify the next permitted step.

Illustrative dispatch review / fictional scenario

Order EX-104 / item P-104

  1. Ask

    Which order needs a dispatch check?

  2. Inspect

    Order: 24 units. Dispatch A: 20 units.

  3. Explain

    The retained note mentions a separate dispatch. Its supporting original is missing.

  4. Decide

    Review the next permitted action before changing an order.
